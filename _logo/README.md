# logo! Seh-Begleiter – Bauanleitung

Täglicher Ablauf (automatisch, ohne PC):
1. Neue Sendung von logo.de in `logo/logo_daten.json` eintragen (inkl. Fragen).
2. `python3 _logo/build_github.py` im Repo-Hauptordner ausführen.
3. Commit + Push → jelle-schule.github.io/logo/ zeigt die neue Sendung.

Ordner mit Unterstrich (`_logo`) werden von GitHub Pages nicht veröffentlicht.
